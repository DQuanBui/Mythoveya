# Mythoveya implementation plan

1. Playable foundation: local client/server, six companions, movement, battle, SQLite saves, initial sound and animation. Check: start, win, reload.
2. Progression: tutorial and daily quests, recruitment with atomic pity, collection and formations. Check: currency and reward replay safety.
3. Multiplayer: Colyseus human rooms, readiness, authoritative timers, two ratings. Check: isolated clients agree on outcomes.
4. Content: 60 species, 180 actions, 60 passives, eight keepers, regions and bosses. Check: complete content matrix and executable mappings.
5. Presentation and verification: portraits, music, voices, effects, gallery, accessibility, tests and project documentation. Check: build/typecheck/tests and browser acceptance path; record review limits.

Use meaningful Git commits at at least ten implementation boundaries. Keep saves out of source control. Create a private GitHub repository if authenticated access permits; never deploy a server.
