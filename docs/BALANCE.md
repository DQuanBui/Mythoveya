# Balance report

Generated by `npm run balance` (`scripts/balance.ts`): 20000 battles between random teams of six distinct species, all at level 20, both sides played by the game's own auto-battler. 0 battles reached the turn limit without a winner, and the average battle lasted 14.7 rounds. Tiers are meant to differ, so each species is compared with the average of its own tier. Win rate means how often a team containing it won; each species played about 2609 battles, so differences of a few points are noise.

This measures the auto-battler's play, not a person's, and ignores equipment, skill levels and formation choices. Treat it as a pointer to what deserves a closer look, not a verdict.
